Environment Setup: This project uses Laravel Sail for local Docker management.
Command Rule: NEVER generate standard docker compose exec commands. Always use the ./vendor/bin/sail prefix for all Artisan, Composer, and Node commands.
Correct: ./vendor/bin/sail artisan migrate
Correct: ./vendor/bin/sail composer require package/name
Correct: ./vendor/bin/sail npm run dev
Incorrect: docker compose exec app php artisan migrate
Database Context: The project uses Supabase (PostgreSQL) as the database. The connection name in Laravel is strictly pgsql (not mysql or pg_sql).
Debugging Database Errors: If encountering database connection issues or migration timeouts:
Check the .env file for correct Supabase credentials (DB_HOST, DB_PORT=5432, DB_USERNAME, DB_PASSWORD).
Check app/Providers/AppServiceProvider.php for any hardcoded or incorrect database connection names (e.g., DB::connection('pg_sql') should be DB::connection('pgsql')).
File Permissions: The Sail container runs as the sail user. Files generated via ./vendor/bin/sail will automatically have the correct host user ownership. No sudo chown commands are needed.
