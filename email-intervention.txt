Update the teacher intervention feature connected to the existing **At-Risk Students** page.

Do not redesign, restructure, or modify the existing At-Risk Students page. Keep its current layout, styling, table, filters, cards, spacing, and interactions exactly as they are.

Only the **new intervention form and its related preview/review UI** should be designed or modified.

## 1. Intervention Scope

The intervention always operates around the **specific student**.

There are two ways to open the intervention:

### Individual Intervention

From:

`At-Risk Students → View Details → Intervene`

This opens an intervention form for exactly one student.

The form must automatically identify that student and use their actual at-risk information.

### Bulk Intervention

From the existing At-Risk Students page, the teacher can select students using the existing/added selection checkboxes and choose to intervene on the selected students.

Bulk intervention must NOT automatically include every student.

The teacher chooses which students to include.

Example:

`[✓] Student A`
`[ ] Student B`
`[✓] Student C`
`[ ] Student D`

Then:

`Intervene (2 selected)`

Only Student A and Student C are processed.

## 2. Bulk Selection

Add selection checkboxes to the student list only as needed to support bulk intervention.

Do not redesign the existing At-Risk Students page.

The teacher must be able to:

* Select individual students
* Select multiple students
* Unselect students
* See how many students are selected
* Start intervention for only the selected students

The bulk action should reflect the current selection count.

For example:

`Intervene (3 selected)`

If no students are selected, the intervention action should not proceed.

## 3. Student-Specific Intervention Logic

Even when the teacher selects multiple students, each student must be processed independently.

The system must evaluate each selected student's actual indicators.

For every student:

`Student`
→ `Actual Academic Indicators`
→ `Actual Attendance Indicators`
→ `Determine At-Risk Condition`
→ `Select Appropriate Template`
→ `Generate Student-Specific Message`
→ `Correct Parent/Guardian Recipient`

Never combine the information of multiple students into one intervention.

For example:

Student A may have:

`Academic Risk`

while Student B may have:

`Attendance Risk`

and Student C may have:

`Academic + Attendance Risk`

Each must receive the appropriate message for their own situation.

## 4. Intervention Form

Create a **medium-compact, modern intervention form**.

The modernization applies ONLY to this intervention feature.

Do not change the visual design of the existing At-Risk Students page.

The form should feel polished and modern while remaining practical for a teacher.

Use a compact card/modal/drawer-style layout with:

* Clear section hierarchy
* Moderate spacing
* Compact form controls
* Clear risk indicators
* Readable typography
* Modern buttons
* Subtle borders/shadows
* Clear primary action
* Responsive layout

Avoid excessive whitespace or an oversized full-page form.

## 5. Individual Intervention Form

For one student, show:

### Student

* Student name
* Section/class
* Subject when applicable

### At-Risk Summary

Show the student's actual indicators and why they were flagged.

For example:

`Academic Risk`
`Current Grade: [actual value]`

or:

`Attendance Risk`
`Attendance Rate: [actual value]`

or:

`Academic + Attendance`
`Current Grade: [actual value]`
`Attendance Rate: [actual value]`

Only display indicators that actually apply to that student.

### Recipient

Show:

`Parent / Guardian`

Use the student's actual parent/guardian contact information available in the system.

### Intervention Message

Show the generated subject and message.

The message must be based on the student's actual risk condition.

## 6. Message Preview

The teacher must be able to preview the **exact message that will be sent**.

The preview should visually resemble a real parent email.

Include:

* Recipient
* Subject
* Message body
* Relevant student information
* Optional teacher note if supported

Make the student identity prominent enough that the teacher can immediately verify:

"This message is for this student."

## 7. Bulk Intervention Form

When multiple students are selected, open the same modern intervention feature but switch it into **bulk review mode**.

The form should clearly indicate:

`3 students selected`

Then display each student's intervention separately.

Example:

### Student A

`Academic Risk`

Current Grade: `72%`

Parent / Guardian: `[actual recipient]`

**Message Preview**

[Student A's generated intervention message]

---

### Student B

`Attendance Risk`

Attendance Rate: `78%`

Parent / Guardian: `[actual recipient]`

**Message Preview**

[Student B's generated intervention message]

---

### Student C

`Academic + Attendance Risk`

Current Grade: `70%`
Attendance Rate: `79%`

Parent / Guardian: `[actual recipient]`

**Message Preview**

[Student C's generated intervention message]

Each student must have an independent message preview.

## 8. Bulk Review Controls

The teacher should be able to review the selected students before sending.

Provide controls such as:

* Back
* Modify Selection
* Review Messages
* Confirm / Send

The teacher must be able to return to the selection step if they realize that a student should not receive the intervention.

Do not assume that selecting students means the teacher must immediately send the messages.

## 9. Template Logic

The appropriate intervention template should be determined from the student's actual risk indicators.

For example:

**Academic Risk**

Use the academic intervention template.

**Attendance Risk**

Use the attendance intervention template.

**Academic + Attendance Risk**

Use the dual-risk intervention template.

The generated message must dynamically populate the correct student's information.

No hardcoded student names, grades, attendance values, sections, or recipients.

## 10. Teacher Recipient

For this teacher-facing intervention feature, the recipient is:

**Parent / Guardian**

The teacher should not need to configure additional recipients.

The correct parent/guardian must be associated with the specific student being processed.

For bulk intervention, each student must retain their own parent/guardian recipient.

## 11. Data Isolation

This is critical.

When processing multiple students, treat every intervention as an independent student-specific object.

For example:

`Student A → Intervention A → Parent A`

`Student B → Intervention B → Parent B`

`Student C → Intervention C → Parent C`

Never produce:

`Student A + Student B + Student C → One mixed message`

Never allow:

* one student's grade to appear in another student's message
* one student's attendance to appear in another student's message
* the wrong parent/guardian to receive a message
* the wrong risk condition to determine the template

## 12. Final UI Flow

### Single Student

`At-Risk Students`
→ `View Details`
→ `Intervene`
→ Modern Medium-Compact Intervention Form
→ Student Risk Summary
→ Generated Message
→ Message Preview
→ Confirm / Send

### Multiple Students

`At-Risk Students`
→ Select desired students
→ `Intervene (X selected)`
→ Modern Medium-Compact Bulk Intervention Form
→ Individual student intervention previews
→ Review
→ Confirm / Send

Again, the modernization applies **only to the intervention form, intervention preview, and bulk intervention review UI**.

Do not redesign or otherwise modernize the existing At-Risk Students page.
