# Environment Variables Reference

This document outlines all configuration keys defined in `.env.example`, detailing their domain purpose, fallback values, and security constraints.

> [!CAUTION]
> **Zero Secrets Policy:** Never commit raw production passwords, private database credentials, or secret API keys to documentation or Git. Always use sanitized placeholders.

---

## Core Application Configuration

| Key | Example Value | Description |
|---|---|---|
| `APP_NAME` | `"Concepcion Integrated School"` | Name of the platform displayed across titles, navbar banners, and PDF exports. |
| `APP_ENV` | `local` / `production` | Active environment. Set to `production` in staging/live environments. |
| `APP_KEY` | `base64:...` | 32-character encryption key generated by `php artisan key:generate`. |
| `APP_DEBUG` | `true` (dev) / `false` (prod) | Toggles detailed stack traces. Must be `false` in production. |
| `APP_URL` | `http://localhost:8000` | Fully qualified base URL used for email links and asset generation. |
| `APP_TIMEZONE` | `Asia/Manila` | Application timezone. Crucial for accurate timestamp comparisons in `AttendanceStateMachine` and daily scan boundaries. |

## Database Configuration

The application defaults to PostgreSQL (`pgsql`) and supports MySQL (`mysql`) or SQLite (`sqlite`).

| Key | Example Value | Description |
|---|---|---|
| `DB_CONNECTION` | `pgsql` | Primary database driver (`pgsql` / `mysql` / `sqlite`). |
| `DB_HOST` | `127.0.0.1` / `your-db-host` | Database server host or Supabase pooler address. |
| `DB_PORT` | `5432` | Database port (PostgreSQL default: `5432`, MySQL: `3306`). |
| `DB_DATABASE` | `<database schema name>` | Database schema name. |
| `DB_USERNAME` | `<database username>` | Database user. |
| `DB_PASSWORD` | `<database password>` | Database user password. |

---

## Queue, Session & Cache Drivers

| Key | Value | Purpose |
|---|---|---|
| `SESSION_DRIVER` | `database` | Stores user sessions in the `sessions` table, enabling role audit tracking and concurrent login controls. |
| `SESSION_LIFETIME` | `120` | Session expiration in minutes. |
| `QUEUE_CONNECTION` | `database` | Queues asynchronous jobs (scan notification emails, bulk student imports) in the `jobs` table. |
| `CACHE_STORE` | `file` | Cache driver for temporary tokens and rate limiters. |

## Real-Time Broadcasting (Laravel Reverb & Echo)

Laravel Reverb powers live QR scan updates on the attendance monitoring screen and scanner kiosk.

| Key | Value | Purpose |
|---|---|---|
| `BROADCAST_CONNECTION` | `reverb` | Broadcast driver. |
| `REVERB_APP_ID` | `[APP_ID]` | Reverb application identifier. |
| `REVERB_APP_KEY` | `[APP_KEY]` | Public websocket connection key. |
| `REVERB_APP_SECRET` | `[APP_SECRET]` | Server-side signature secret. |
| `REVERB_HOST` | `localhost` | Reverb server hostname. |
| `REVERB_PORT` | `8080` | Websocket server port. |
| `REVERB_SCHEME` | `http` (local) / `https` (prod) | Websocket transport protocol. |
| `VITE_REVERB_APP_KEY` | `${REVERB_APP_KEY}` | Passed to frontend Vite bundle (`resources/js/echo.js`). |
| `VITE_REVERB_HOST` | `${REVERB_HOST}` | Host for browser WebSocket connection. |
| `VITE_REVERB_PORT` | `${REVERB_PORT}` | Port for browser WebSocket connection. |
| `VITE_REVERB_SCHEME` | `${REVERB_SCHEME}` | Scheme for browser WebSocket connection. |

## Mail Configuration

Used to send scan entry/exit alerts to guardians and invitation tokens to new teachers/administrators.

| Key | Example Value | Description |
|---|---|---|
| `MAIL_MAILER` | `smtp` | Mail driver (`smtp`, `log` for local debugging). |
| `MAIL_HOST` | `smtp.gmail.com` / `smtp-relay.brevo.com` | SMTP host provider. |
| `MAIL_PORT` | `587` | SMTP port (typically 587 for TLS, 465 for SSL). |
| `MAIL_USERNAME` | `your_email@example.com` | Authenticated SMTP account. |
| `MAIL_PASSWORD` | `[APP_PASSWORD_PLACEHOLDER]` | SMTP application-specific password. |
| `MAIL_ENCRYPTION` | `tls` | Transport security (`tls` or `ssl`). |
| `MAIL_FROM_ADDRESS` | `noreply@cis.edu.ph` | Outgoing system sender email address. |
| `MAIL_FROM_NAME` | `"CIS Attendance Station"` | Sender name shown in guardian inbox. |
