USER CREATION RULES

1. Only Admin can create users.

2. Admin provides:
   - Name
   - Email
   - Role

3. Admin does NOT provide or see the user's password.

4. Newly created users have:
   status = PENDING

5. The system generates a secure, random,
   single-use invitation token.

6. The invitation token must have an expiration time.

7. The invitation is sent to the user's registered email.

8. The user must create their own password through
   the invitation link.

9. The password must be securely hashed before storage.

10. After successful password setup:
      PENDING → ACTIVE

11. The invitation token must become unusable after
    successful account setup.

12. Expired or already-used invitation links must
    not allow account setup.

13. Admin can resend an invitation for PENDING users.

14. Admin can deactivate an ACTIVE user.

15. Deactivated users must not be able to log in.

16. User role determines accessible system functionality.

17. The system must never display or reveal a user's
    password to the Admin.
