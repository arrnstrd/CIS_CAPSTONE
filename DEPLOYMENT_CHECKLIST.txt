================================================================================
COMMON ISSUES & QUICK FIXES
================================================================================

ISSUE: "Overview cards show 0 for all counts"
  FIX: Check timezone in config/app.php
       Verify last_attempt_at column has data
       Check date range logic in scopeTodayOnly()

ISSUE: "Filters not working"
  FIX: Check request parameters are being passed
       Verify query scopes are on EmailLog model
       Check database data for expected values

ISSUE: "Pagination broken"
  FIX: Verify withQueryString() is on pagination
       Check for missing query parameters in request
       Test with simple URL (no special characters)

ISSUE: "Retry button not showing"
  FIX: Verify database stores 'failed' (lowercase)
       Check Blade uses === not ==
       Verify email status in database

ISSUE: "Help modal not opening"
  FIX: Check Bootstrap is loaded (should be)
       Verify modal HTML structure
       Check data-bs-toggle="modal" on Help button

For more issues, see: DOCUMENTATION_EMAIL_LOGS_REFACTOR.txt > 10. DEBUGGING GUIDE
