QUERY SCOPES ADDED:
────────────────────

1. scopeFilterByDateRange($startDate, $endDate)
   - Filters by date range (inclusive)
   - Accepts Carbon or string dates

2. scopeTodayOnly()
   - Filter for today's logs
   - Used as default

3. scopeYesterdayOnly()
   - Filter for yesterday's logs

4. scopeLast7Days()
   - Filter for last 7 days (6 days ago + today)

5. scopeFilterByStatus($status)
   - Single status or array of statuses
   - Used in statistics calculation


CONTROLLER METHODS:
────────────────────

index(Request $request)
  - Extracts filter parameters
  - Builds base query with filters
  - Calculates statistics from full filtered set
  - Applies pagination
  - Returns view with data

applyDateFilter($query, $dateFilter, $customStart, $customEnd)
  - Private helper
  - Applies appropriate scope based on filter type
  - Handles custom date range

getFilteredStatistics($query)
  - Private helper
  - Returns: ['total', 'sent', 'failed', 'pending']
  - Uses cloned queries to preserve original


BLADE VARIABLES PASSED:

$emailLogs       - Paginated collection with 'student' eager loaded
$emailCounts     - Array: ['total', 'sent', 'failed', 'pending']
$dateFilter      - Current date filter selection
$customStartDate - Start date for custom range (if selected)
$customEndDate   - End date for custom range (if selected)
