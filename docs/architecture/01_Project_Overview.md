# Project Overview

## Project Title

WEB-BASED QR STUDENT ATTENDANCE MONITORING WITH CENTRALIZED ACADEMIC MANAGEMENT SYSTEM FOR CONCEPTION INTEGRATED SCHOOL

## Technology Stack

- Laravel
- PHP
- MySQL
- Bootstrap 5
- MVC Architecture

## Current Project Status

The project already contains an existing implementation for:

- User Management
- Student Management
- Guardian Management
- Academic Setup
- QR Code Generation
- Gate Attendance
- Teacher Management
- Teaching Assignments

The current database is represented by `CURRENT_DATABASE.json`.

The target architecture is represented by `FINAL_ERD.dbml`.

The goal is to migrate the current implementation into the final architecture while preserving existing functionality.
